# 结果与历史记录约定

实质变更交付或必要阶段留档时，在 `histories/` 更新同一任务的一份记录；纯问答和普通测试执行留在会话中。

记录用户诉求、主要变化、设计理由、被测版本或工作区范围、关键验证结论、待验证事项及证据位置。长期规则链接 `design/`，待办链接活动计划，日志与截图链接正常产物位置。

历史测量标明日期、版本、工具与合成/真实场景，后续修改不抹去失败条件，也不把旧结果更新成未经执行的新结果。版本或协议过期时注明适用范围。

使用[历史模板](histories/template.md)。保留已有发布记录与上游来源署名；原文件的 Git 提交可追溯，无需额外建立 archive 或迁移副本。共享文档不写密钥、完整用户目录或原始敏感日志。
