## 环境与实测缺口

- 本轮 native build 因主机内存压力中断；用户随后明确改用 GitHub 远程构建。已有旧版原生模拟服务结果不能代替当前发布提交的结果。
- Rust 测试临时目录放在仓库内时，Git 曾向上发现主仓库，造成 10 个隔离夹具失败。设置 `GIT_CEILING_DIRECTORIES` 为绝对 `.Sinos-temp` 目录后，完整套件 753 项通过；生产逻辑与断言未改。
- 用户报告真实 Claude 历史接续可用；Codex 曾因全局 npm 可选 Windows 依赖缺失启动失败。已按用户指示安装 Codex 0.167.2，并核对版本与平台二进制；本会话尚未执行真实账号续聊。
- 真实语音服务/麦克风、系统剪贴板/通知交互、物理手机及最新非 Windows 原生程序仍需对应环境。既有手机/Android 前端、模拟协议和本地中继测试分别按其范围报告。
