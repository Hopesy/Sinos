# 执行计划约定

跨模块、分阶段或需要跨会话接续的目标使用一份计划，小修改直接沿用已有清单。

- `exec-plans/active/`：未完成目标，包括已实现但仍待验收或外部阻塞的工作。
- `exec-plans/completed/`：达到原始验收条件的计划。
- [空白模板](exec-plans/templates/execution-plan.md)：新目标的可复用起点。
- [技术债](exec-plans/tech-debt-tracker.md)：当前目标之外已证实的问题。

计划顶部保持接续摘要：当前目标、最新用户约束及来源、当前切片、被测版本/工作区范围、实际结果与证据、待验证项、下一动作和阻塞。里程碑用用户能验收的结果表达，状态采用待实施、已实现待验证、已验证、待核对。

用户修正及时写回约束；重要检查点更新进度。原目标未完成时保留 active 状态，避免用计划完成代替产品完成。归档前把长期规则收拢到架构或 design，history 只链接结论与关键证据。

决定使用 `accepted`、`proposed`、`rejected`、`superseded`；替代决定写仓库相对路径的 `superseded_by`，核对目标与章节存在后采用。
