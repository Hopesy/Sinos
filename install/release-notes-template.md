### Sinos CLI v4.0.5

- **任务通知与完成角标。** Windows 可在 Agent 完成任务、需要回答或授权时弹出通知，点击返回对应会话；任务栏显示未读完成数量，查看会话后清除。通知、角标和提醒范围可分别设置。
- **多会话更省内存。** 隐藏会话释放 Markdown 与代码高亮渲染内容，清理流式消息的过期尺寸缓存；每会话原始输出回放缓存限制为 2 MiB，保留会话状态和阅读位置。
- **全新启动体验。** Sinos 启动动画适配主题、缩放与减少动态效果；轻量首屏和工作区并行加载，后台维护移出窗口初始化流程。
- **关闭时收起到托盘。** 在通用设置中选择关闭行为，点击 X 后可保留后台会话，通过托盘恢复或退出；新增设置采用紧凑的分段选择与开关列表。
- **原生对话与完整工作区。** 支持 Claude、Codex、DeepSeek Harness 原生对话、权限问答、模型控制及多会话分屏；完善 Sinos Agent、任务编排、用量历史、Git/PR/CI 和代码审查。
- **运行更稳定。** 修复 Windows 窗口闪烁、子进程残留、初始化关闭与重连竞态、监听失败后的恢复及重复完成提醒；改善历史恢复、快捷键归属、移动端工具筛选和文件预览。

### Sinos CLI v4.0.5

- **Close to the system tray.** Choose the close behavior in General settings to keep sessions running after clicking X, then restore or quit from the tray. Compact segmented controls and switches simplify the new preferences.
- **Native conversations and a richer workspace.** Use Claude, Codex and DeepSeek Harness conversations, permissions, questions, model controls and split views, with improvements to Sinos Agent, orchestration, usage, history, Git/PR/CI and code review.
- **More reliable operation.** Fix Windows window flashing, surviving child processes, initialization and reconnect races, listener recovery and duplicate completion alerts. Improve history restoration, keyboard ownership, mobile tool filtering and file previews.

### Sinos CLI v4.0.5

- **작업 알림과 완료 배지.** Windows에서 Agent의 작업 완료, 답변 및 승인 요청을 알리고 클릭하면 해당 대화로 돌아갑니다. 작업 표시줄에 읽지 않은 완료 수를 표시하며 대화를 보면 지워집니다. 알림, 배지, 알림 범위를 개별 설정할 수 있습니다.
- **여러 대화의 메모리 사용량 감소.** 숨겨진 Markdown과 구문 강조 렌더링을 해제하고 스트리밍 메시지의 오래된 크기 캐시를 정리합니다. 원시 출력 재생 캐시는 세션당 2 MiB로 제한하며 대화 상태와 읽던 위치를 유지합니다.
- **새로운 시작 경험.** Sinos 시작 화면은 테마, 배율, 동작 줄이기 설정을 따릅니다. 가벼운 시작 화면과 작업 공간을 함께 불러오며 유지 관리 작업을 창 초기화에서 분리했습니다.
- **닫을 때 시스템 트레이에 유지.** 일반 설정에서 선택하면 X를 눌러도 세션이 계속 실행됩니다. 트레이에서 복원하거나 종료할 수 있으며 새 설정은 간결한 선택 버튼과 스위치로 구성했습니다.
- **네이티브 대화와 풍부한 작업 공간.** Claude, Codex, DeepSeek Harness의 대화, 권한 확인, 질문, 모델 제어 및 분할 화면을 지원합니다. Sinos Agent, 작업 연계, 사용량과 기록, Git/PR/CI 및 코드 검토를 개선했습니다.
- **안정적인 실행.** Windows 창 깜박임, 자식 프로세스 잔류, 초기화 및 재연결 충돌, 이벤트 수신 복구와 중복 완료 알림을 수정했습니다. 기록 복원, 키 입력 처리, 모바일 도구 목록과 파일 미리보기도 개선했습니다.
