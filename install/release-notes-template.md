### Sinos CLI v4.0.7

- **新增 OpenCode 与 Pi 原生对话。** 支持流式回复、工具卡片、模型与思考强度设置、权限问答及任务编排；OpenCode 原生对话需要 2.0 或更新版本。
- **独立工作区与更灵活的协作。** 对话和子任务可使用 Git Worktree，查看并合并分支改动；新增编排角色、运行中任务引导和重启后的工作记录。
- **自动任务与预输入笔记。** 按指定时间或周期运行任务；保存待发送内容，点击笔记追加到当前输入框。
- **语音输入。** 新增麦克风选择、输入测试和可用语音服务发现，支持在对话输入区使用语音转写。
- **更完整的会话信息。** 改善 Claude／Codex 历史接续和 DeepSeek 工具展示，新增每轮耗时、用量与费用摘要；Sinos Agent 可记录经过验证的项目经验。
- **界面与个性化升级。** 全窗口设置、新主题、JetBrains Mono 字体、自定义提醒声音、文件路径链接，以及窗口尺寸和位置记忆。
- **更新与稳定性改进。** 完善 macOS／Linux 应用内更新下载与校验，保护工作区文件和续接草稿；修复录音编辑冲突、过期问答、并发消息、历史缓存及设置页快捷键问题。
- **手机连接更稳定。** 修复多个桌面实例在后台反复抢连中继的问题，支持手动接管连接，并隔离开发版与正式版的配对配置。
- **统一 Sinos 图标。** 更新桌面文件主题、手机页面和主屏幕图标，清理旧 Coffee 图片及闲置图标资源，保留已有主题选择。

### Sinos CLI v4.0.7

- **Native OpenCode and Pi conversations.** Stream replies, inspect tool cards, choose models and reasoning effort, answer permission prompts and coordinate tasks. Native OpenCode conversations require version 2.0 or later.
- **Isolated workspaces and more flexible collaboration.** Use Git worktrees for conversations and workers, inspect and merge branch changes, choose coordinator roles, steer running tasks and recover work notes after restarting.
- **Automations and pre-input notes.** Schedule one-time or recurring tasks, save text for later, and click a note to append it to the current composer.
- **Voice input.** Choose and test a microphone, discover available speech services and transcribe speech directly into the composer.
- **Richer conversation details.** Improve Claude/Codex history continuation and DeepSeek tool output, with per-turn duration, usage and cost summaries. Sinos Agent can retain verified project experiences.
- **Interface and personalization improvements.** Full-window settings, new themes, JetBrains Mono, custom notification sounds, file-path links and remembered window size and position.
- **Updates and reliability.** Improve in-app installer downloads and verification on macOS/Linux, protect workspace files and continuation drafts, and fix voice-edit conflicts, expired dialogs, concurrent messages, history caching and keyboard ownership while Settings is open.
- **More stable phone connections.** Stop background relay reconnection conflicts between desktop instances, add explicit connection takeover, and separate development and production pairing settings.
- **Consistent Sinos artwork.** Update desktop file themes, phone screens and home-screen icons; remove retired Coffee images and unused icon resources while preserving saved theme choices.

### Sinos CLI v4.0.7

- **自動工作與預輸入筆記。** 依指定時間或週期執行工作；儲存待傳送內容，點擊筆記即可附加至目前的輸入框。
- **語音輸入。** 新增麥克風選擇、輸入測試及可用語音服務探索，支援在對話輸入區使用語音轉寫。
- **更完整的會話資訊。** 改善 Claude／Codex 歷史接續與 DeepSeek 工具展示，新增每輪耗時、用量及費用摘要；Sinos Agent 可記錄經過驗證的專案經驗。
- **介面與個人化升級。** 全視窗設定、新主題、JetBrains Mono 字型、自訂提醒音效、檔案路徑連結，以及視窗尺寸與位置記憶。
- **更新與穩定性改善。** 完善 macOS／Linux 應用程式內更新下載及校驗，保護工作區檔案與接續草稿；修復錄音編輯衝突、過期問答、並行訊息、歷史快取及設定頁快捷鍵問題。
- **手機連線更穩定。** 修復多個桌面執行個體在背景反覆搶連中繼的問題，支援手動接管連線，並隔離開發版與正式版的配對設定。
- **統一 Sinos 圖示。** 更新桌面檔案主題、手機頁面與主畫面圖示，清理舊 Coffee 圖片及閒置圖示資源，保留既有主題選擇。

- **OpenCode와 Pi 네이티브 대화.** 스트리밍 응답, 도구 카드, 모델과 추론 강도 설정, 권한 확인 및 작업 연계를 지원합니다. OpenCode 네이티브 대화에는 2.0 이상이 필요합니다.
- **독립 작업 공간과 유연한 협업.** 대화와 작업자에 Git Worktree를 사용하고 브랜치 변경을 확인·병합할 수 있습니다. 조정 역할 선택, 실행 중인 작업에 추가 지시, 재시작 후 작업 기록도 추가했습니다.
- **자동 작업과 사전 입력 메모.** 일회성 또는 반복 작업을 예약하고 나중에 보낼 내용을 저장할 수 있습니다. 메모를 클릭하면 현재 입력창에 내용이 추가됩니다.
- **음성 입력.** 마이크 선택과 테스트, 사용 가능한 음성 서비스 검색, 입력창에서의 음성 받아쓰기를 지원합니다.
- **풍부한 대화 정보.** Claude/Codex 기록 이어가기와 DeepSeek 도구 출력을 개선하고 턴별 소요 시간, 사용량 및 비용 요약을 추가했습니다. Sinos Agent는 검증된 프로젝트 경험을 기록할 수 있습니다.
- **인터페이스와 개인화 개선.** 전체 창 설정, 새 테마, JetBrains Mono, 사용자 지정 알림음, 파일 경로 링크, 창 크기와 위치 저장을 추가했습니다.
- **업데이트와 안정성 개선.** macOS/Linux 앱 내 업데이트 다운로드와 검증을 개선하고 작업 공간 파일과 대화 이어가기 초안을 보호합니다. 녹음 중 편집 충돌, 만료된 질문, 동시 전송, 기록 캐시 및 설정 화면의 키 입력 문제를 수정했습니다.
- **더 안정적인 휴대폰 연결.** 여러 데스크톱 인스턴스가 백그라운드에서 중계 연결을 반복해서 가져오는 문제를 수정했습니다. 수동 연결 인수를 추가하고 개발판과 정식판의 페어링 설정을 분리했습니다.
- **Sinos 아이콘으로 통일.** 데스크톱 파일 테마, 휴대폰 화면과 홈 화면 아이콘을 업데이트했습니다. 저장된 테마 선택을 유지하면서 이전 Coffee 이미지와 사용하지 않는 아이콘 리소스를 정리했습니다.
