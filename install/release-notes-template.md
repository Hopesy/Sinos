### Sinos CLI v3.6.0

- **在手机上继续桌面的编码会话。** 通过 Cloudflare 加密中继配对，手机与电脑共享同一个 CLI 会话，可查看项目文件、编辑文件和审查 Git 变更。
- **移动端采用对话式界面。** 同步原生会话记录与终端进度，连续工具操作可分组展开，代码支持高亮与复制，文件编辑支持片段差异展示。
- **补齐移动协作操作。** 支持已识别的终端单选、多选和文字问答，以及图片附件和待发送队列；Claude/Codex 的自动队列等待可验证的本轮结束记录。
- **改进连接与显示。** 中继地址位于设置顶部并提供测试按钮，支持深浅主题、窄屏和键盘高度布局。修复 Claude 生成动画切换、启动菜单识别和状态栏横线堆积的问题。
- **模型和目录信息集中展示。** 状态栏与输入区整合，工具失败和未收到结果的状态保持可见，展开工具记录时可稳定阅读。

使用前请保持电脑端运行，在设置的移动连接页面完成配对。自定义 CLI 菜单仍可能无法转换成手机控件。

### Sinos CLI v3.6.0

- Continue a desktop CLI session from your phone through an encrypted Cloudflare relay, with project files, file editing and Git changes available in the mobile workspace.

Keep the desktop app running and pair your phone from mobile connection settings. Some custom CLI menus cannot yet be converted to mobile controls.
